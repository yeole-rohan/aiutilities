Frequently Asked Questions

Are the passwords generated securely? ▼
Yes — passwords are generated using the browser's crypto.getRandomValues() API, which provides cryptographically secure randomness. Nothing is sent to any server. Generation happens entirely in your browser.
How long should my password be? ▼
Security experts recommend at least 12–16 characters for personal accounts and 20+ for high-value accounts. Longer passwords with mixed character types are exponentially harder to crack.
Should I use a password manager? ▼
Yes — a password manager lets you use a unique, strong password for every site without memorising them. Generate a password here, then store it in a manager like Bitwarden, 1Password, or Dashlane.
