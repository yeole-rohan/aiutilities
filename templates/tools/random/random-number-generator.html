Frequently Asked Questions

Is this truly random? ▼
This tool uses the browser's built-in Math.random(), which is a pseudorandom number generator (PRNG). It is random enough for most everyday uses like games, decisions, and sampling — but not suitable for cryptographic purposes.
How does no-duplicates mode work? ▼
The generator keeps track of already-picked numbers and skips repeats. Note that the count cannot exceed the number of distinct integers in your range when no-duplicates is enabled.
Can I simulate a dice roll? ▼
Yes — set min to 1 and max to 6 for a standard d6. For a d20, use 1–20. You can generate multiple dice rolls at once by increasing the count.
