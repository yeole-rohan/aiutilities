Random Name Generator

Generate random names for testing, character creation, or games. Choose gender, style, and how many names you need.

How to Use the Name Generator

1
Choose gender and style
Pick a gender filter (or any) and select a naming style — Western, Latin, Nordic, or Fantasy.
2
Set format and count
Choose full name, first only, or last only. Set how many names you need (up to 200).
3
Generate and copy
Click Generate. The names appear as tags. Click Copy to copy them all to your clipboard as a newline-separated list.

Frequently Asked Questions

Are the names real names? ▼
The names are drawn from curated word lists of common first and last names in the selected style. They are all real-sounding names but the combinations are randomly generated, so they are unlikely to be real people.
What can I use random names for? ▼
Common uses include: populating test databases, creating placeholder user accounts, writing fiction characters, generating NPC names for games, and anonymising datasets for demos.
