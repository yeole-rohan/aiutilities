How to Use the Random Picker

1
Enter your items
Type or paste your list of options — one per line. These can be names, tasks, dinner choices, or anything else.
2
Set options and pick
Choose how many items to pick and whether to remove them from the list. Click Pick to get your result.
3
Keep picking or start over
Picks are shown in a history log. Enable Remove mode to draw without repeats until the list is empty.

Frequently Asked Questions

Is the result truly random? ▼
Yes — each item in the list has an equal probability of being selected. The tool uses the browser's pseudorandom number generator, which is unpredictable enough for all everyday decision-making purposes.
Can I pick more than one item at once? ▼
Yes — change the "items to pick" number to select multiple winners at once. When remove mode is on, each picked item is removed so duplicates are impossible.
