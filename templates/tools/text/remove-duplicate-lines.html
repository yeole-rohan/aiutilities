Frequently Asked Questions

Does it preserve order? ▼
Yes — by default the first occurrence of each line is kept and later duplicates are removed, preserving the original order.
What does "ignore case" do? ▼
When enabled, "Apple", "APPLE", and "apple" are treated as the same value and only the first occurrence is kept.
Can I use it to deduplicate email lists? ▼
Yes — paste one email address per line and it will remove duplicate rows instantly.
