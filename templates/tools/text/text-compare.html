Frequently Asked Questions

Is this a word-level or line-level diff? ▼
This tool performs a line-level diff — each line is compared as a whole. Lines that differ are shown as a removed line (red) followed by the added version (green). This is the most readable format for prose and config files.
Is there a size limit? ▼
No hard limit, but very large texts (thousands of lines) may take a moment to process. For files over a few MB, a dedicated git diff tool is faster.
Is case-sensitivity considered? ▼
Yes — the diff is case-sensitive by default. "Hello" and "hello" will be shown as different lines. This is consistent with how most code diff tools work.
