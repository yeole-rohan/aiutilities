When to Use Each Case

camelCase

JavaScript variables and function names. First word lowercase, subsequent words capitalised: myVariableName.

PascalCase

Class names, React components, TypeScript interfaces. Every word capitalised: MyComponent.

snake_case

Python variables, database column names, file names. Words separated by underscores: my_variable.

kebab-case

CSS class names, HTML attributes, URLs. Words joined by hyphens: my-class-name.

Frequently Asked Questions

What is camelCase? ▼
camelCase joins words without spaces, capitalising each word except the first — e.g. myVariableName. It is the standard convention for JavaScript variables and functions.
What is the difference between PascalCase and camelCase? ▼
PascalCase capitalises every word including the first — e.g. MyClassName. It is commonly used for class names and React components.
What is Title Case? ▼
Title Case capitalises the first letter of every word — e.g. The Quick Brown Fox. It is standard for book titles and headings.
Does the converter handle accented characters? ▼
Yes — Unicode letters are preserved when converting case, so accented characters like e-acute or u-umlaut are handled correctly.
