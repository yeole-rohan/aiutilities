Frequently Asked Questions

What is an MD5 hash? ▼
MD5 is a hash function that produces a fixed 128-bit (32 hex character) fingerprint for any input. The same input always produces the same hash; even a tiny change produces a completely different hash.
Is MD5 secure for passwords? ▼
No — MD5 is broken for security purposes. It is fast and vulnerable to rainbow table attacks. Use bcrypt, scrypt, or Argon2 for password hashing.
What is MD5 still used for? ▼
File integrity checks (verifying a download was not corrupted), non-security checksums, cache keys, and legacy systems. Never use it for passwords or digital signatures.
