Frequently Asked Questions

What is the difference between SHA-256 and SHA-512? ▼
SHA-256 produces a 256-bit (64 hex character) hash; SHA-512 produces a 512-bit (128 hex character) hash. SHA-512 provides more security but is larger. Both are considered secure.
Is SHA-1 still safe to use? ▼
No — SHA-1 has known collision vulnerabilities and should not be used for new security applications. Use SHA-256 or SHA-512 instead.
What does this use under the hood? ▼
This tool uses the browser native SubtleCrypto API (crypto.subtle.digest()), which is implemented in native code for accuracy and speed.
