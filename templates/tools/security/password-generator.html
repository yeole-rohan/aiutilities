Password Security Tips

1

Use a password manager

You shouldn't remember passwords — a password manager does that. Use a unique 16+ character random password for every account.

2

Enable two-factor authentication (2FA)

Even with a strong password, enable 2FA on all important accounts. A leaked password alone won't grant access.

3

Never reuse passwords

If one site is breached, attackers try those credentials everywhere (credential stuffing). Unique passwords per site contain any breach.

Frequently Asked Questions

How long should my password be? ▼
Security experts recommend at least 16 characters for important accounts, and 20+ for critical ones like your password manager master password.
Is this generator truly random? ▼
Yes — it uses the browser's window.crypto.getRandomValues() API, which provides cryptographically secure random numbers, not the weaker Math.random().
Should I use a password manager? ▼
Yes — a password manager lets you use a unique, long, random password for every site without memorising them. Combined with this generator, it is the most secure approach.
