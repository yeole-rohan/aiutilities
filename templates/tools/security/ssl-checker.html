What an SSL Certificate Contains

Domain (CN / SAN)

The domain name(s) the certificate is valid for. Modern certificates use Subject Alternative Names (SAN) to cover multiple domains and subdomains in one cert.

Issuer (CA)

The Certificate Authority that signed the certificate (e.g. Let's Encrypt, DigiCert, Sectigo). Browsers trust certs signed by known CAs in their root store.

Validity Period

Not-Before and Not-After dates. Certificates are typically valid for 90 days (Let's Encrypt) to 1–2 years. Expired certs cause browser warnings that scare away visitors.

Certificate Type

DV (Domain Validated), OV (Organization Validated), or EV (Extended Validation). DV certs only prove domain control — OV/EV verify the legal entity behind the domain.

Frequently Asked Questions

What happens if my SSL certificate expires? ▼
Browsers show a full-page warning ("Your connection is not private") and block access. Search engines may de-rank the site. Users will mostly leave immediately. Let's Encrypt auto-renews every 60–90 days if configured correctly.
Is Let's Encrypt safe to use? ▼
Yes — Let's Encrypt is a trusted, free CA operated by the non-profit Internet Security Research Group (ISRG). It issues DV certificates trusted by all major browsers. It's used by millions of websites including major platforms.
What is HSTS? ▼
HTTP Strict Transport Security tells browsers to always connect via HTTPS for a specified duration (max-age), even if the user types http://. Once a browser sees this header, it refuses to downgrade to plain HTTP, protecting against SSL stripping attacks.
