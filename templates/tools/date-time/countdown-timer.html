Frequently Asked Questions

Does the countdown use my local timezone? ▼
Yes — the datetime-local input and the countdown calculation both use your browser's local timezone. If you set a countdown for midnight and you're in New York, it counts down to midnight New York time.
Will the countdown keep running if I leave the tab? ▼
The countdown calculates based on the target date minus the current time, so when you return to the tab it will show the correct remaining time even if it was not visible.
