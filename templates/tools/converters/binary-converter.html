Number Bases Cheat Sheet

Binary (Base 2)

Uses only 0 and 1. The language of computers. Each digit is a bit. 8 bits = 1 byte. Used in bitwise operations, flags, and low-level programming.

Octal (Base 8)

Uses digits 0–7. Historically used in Unix file permissions (e.g., chmod 755). Less common today but still appears in legacy systems.

Decimal (Base 10)

Uses digits 0–9. The standard number system humans use. All other bases convert through decimal as an intermediate step.

Hex (Base 16)

Uses 0–9 and A–F. Compact representation of binary — each hex digit = 4 bits. Used in colors (#FF5733), memory addresses, and cryptographic hashes.

Frequently Asked Questions

What is a binary number? ▼
Binary (base-2) uses only 0 and 1. Each digit represents a power of 2. For example, binary 1010 equals 8+0+2+0 = 10 in decimal.
What is hexadecimal used for? ▼
Hexadecimal (base-16, using 0–9 and A–F) is used in programming because one hex digit represents exactly 4 binary bits, making large binary values more compact and readable.
What is an octal number? ▼
Octal (base-8, digits 0–7) is used in Unix file permissions. For example, chmod 755 means owner can read/write/execute (7), group and others can read/execute (5).
