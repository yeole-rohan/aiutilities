Frequently Asked Questions

Which format should I choose? ▼
Use JPG for photos, PNG for images with transparency or sharp-edged graphics, and WebP for web use when file size matters. WebP offers the best compression for web photos.
Can I convert a GIF? ▼
Yes, but only the first frame of the GIF will be converted, since HTML5 canvas does not support multi-frame animation. The result will be a static image.
Will transparency be preserved? ▼
PNG and WebP support transparency. JPG does not — transparent areas will be filled with the background color you choose. PNG→PNG preserves transparency fully.
