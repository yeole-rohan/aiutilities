Frequently Asked Questions

Is my API key safe? ▼
Yes — your API key is only used to make the direct API call from your browser to remove.bg. It is never stored in a database or sent to our servers. Clear your browser storage after use if on a shared device.
What image types work best? ▼
Images with clear subjects against distinct backgrounds work best — people, animals, products, cars. Transparent objects, fine hair, and complex patterns are more challenging but remove.bg's AI still handles them well.
How many free uses do I get? ▼
The free remove.bg tier gives 50 API previews (small previews up to 0.25 MP) per month. For full-resolution output, paid credits start at a fraction of a cent per image.
