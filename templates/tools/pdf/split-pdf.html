Frequently Asked Questions

Are my files private? ▼
Yes — all PDF processing runs in your browser using pdf-lib. Files are never uploaded to any server.
Can I extract multiple non-consecutive pages? ▼
Currently the range mode extracts consecutive pages. To extract non-consecutive pages, use "split all pages" then merge the ones you need with the Merge PDF tool.
What if my PDF has 100+ pages? ▼
Splitting all pages will trigger 100+ individual downloads. Most browsers will ask for permission. Use the range mode to extract just the pages you need.
