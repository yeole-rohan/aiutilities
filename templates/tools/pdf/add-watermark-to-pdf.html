Frequently Asked Questions

Can the watermark be removed? ▼
The text watermark is drawn directly onto each page as PDF vector graphics. While it can be removed with PDF editing software, it provides a visible deterrent and clearly marks the document's status.
Does it work on scanned PDFs? ▼
Yes — the watermark is placed on top of the page content regardless of whether the PDF contains text, images, or scanned pages.
Are my files private? ▼
Yes — everything runs locally in your browser using pdf-lib. Nothing is uploaded to any server.
