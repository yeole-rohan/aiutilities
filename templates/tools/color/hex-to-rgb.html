Frequently Asked Questions

How does hex color work? ▼
A hex color is a 6-digit hexadecimal number (e.g. #FF6B6B) where each pair of digits represents Red, Green, and Blue channels from 00 to FF (0–255 in decimal). Shorthand like #F0F expands to #FF00FF.
What is normalized color (0–1 range)? ▼
Normalized values divide each RGB channel by 255, giving a float between 0 and 1. This format is used by OpenGL, WebGL, Three.js, Blender, and many other graphics APIs and game engines.
When should I use HSL instead of RGB? ▼
HSL (Hue, Saturation, Lightness) is more intuitive for humans because you can adjust brightness or saturation without changing the hue. It is great for creating color scales and theming where you want consistent relationships between shades.
