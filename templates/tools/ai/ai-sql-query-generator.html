Frequently Asked Questions

How accurate is the generated SQL?
Very accurate for standard queries. Providing your schema (table names and column names) dramatically improves accuracy — the AI can generate the exact column references instead of guessing. Always test queries on a development database before running on production data.
Can it generate INSERT, UPDATE, and DELETE queries?
Yes — describe what you want to write, update, or delete in the description field. For data-modifying queries (UPDATE, DELETE), the AI will include appropriate WHERE clauses and warn about scope — always review before executing a bulk update or delete.
