What WHOIS Tells You

Registrar

The company where the domain was purchased (e.g. GoDaddy, Namecheap, Google Domains). Useful when transferring domains.

Dates

Registration date (when the domain was first created), last updated, and expiry date. Check expiry to see if a domain is about to become available.

Status

ICANN status codes like clientTransferProhibited, serverDeleteProhibited, and redemptionPeriod indicate the domain's lock and lifecycle state.

Nameservers

The DNS servers authoritative for the domain. Changing nameservers is how you point a domain to a different hosting provider.

Frequently Asked Questions

Why is registrant contact information hidden? ▼
GDPR and most registrars now redact personal contact data by default (WHOIS privacy). You'll see "Redacted for privacy" or the registrar's proxy contact details instead.
What is RDAP? ▼
RDAP (Registration Data Access Protocol) is the modern JSON-based successor to the old WHOIS protocol. It provides structured, machine-readable domain registration data and supports access control.
What does "clientTransferProhibited" mean? ▼
This ICANN status code means the domain is locked at the registrar level — it cannot be transferred to another registrar without the current registrar explicitly unlocking it first.
