What IP Lookup Tells You

Geolocation

Country, region, city, postal code, and GPS coordinates (latitude/longitude). Accuracy varies — city-level is approximate.

ISP & ASN

Internet Service Provider name, organization, and Autonomous System Number (ASN) — the routing identity of the network.

Timezone

IANA timezone name and UTC offset — useful for scheduling and server configuration.

Connection Type

Whether the IP is a hosting provider, VPN, Tor exit node, proxy, or a regular residential/business connection.

Frequently Asked Questions

How accurate is IP geolocation? ▼
Country-level accuracy is ~99%. City-level is typically within 25–50 miles for most IPs. Mobile and VPN IPs can be much less accurate.
Can I look up private IPs? ▼
Private IPs (192.168.x.x, 10.x.x.x, 172.16–31.x.x) are not routable on the public internet, so they have no geolocation data. The API will return an error for these.
Is the lookup data stored? ▼
No. Your query goes directly from your browser to the ipapi.co API. We do not log or store any IP addresses you look up.
