HTTP Status Code Reference

2xx — Success

200 OK — request succeeded.
201 Created — resource created.
204 No Content — success with no body (e.g. after DELETE).

3xx — Redirects

301 Moved Permanently — URL has changed forever (SEO juice passes).
302 Found — temporary redirect.
307/308 — preserve HTTP method on redirect.

4xx — Client Errors

400 Bad Request — malformed request.
401 Unauthorized — auth required.
403 Forbidden — no permission.
404 Not Found — page doesn't exist.

5xx — Server Errors

500 Internal Server Error — generic server fault.
502 Bad Gateway — upstream failed.
503 Service Unavailable — overloaded or down.

Frequently Asked Questions

Why do some URLs show "CORS blocked"? ▼
Browsers enforce CORS (Cross-Origin Resource Sharing) policies. Many servers block cross-origin requests, so the browser cannot read the response status. A CORS block on its own usually means the server is live and responding — it's not a 404 or 5xx.
What's the difference between 301 and 302? ▼
301 is a permanent redirect — search engines transfer link equity (PageRank) to the destination and update their index. 302 is temporary — search engines keep the original URL indexed and don't pass full link equity.
How many URLs can I check at once? ▼
Up to 20 URLs per batch. All requests run in parallel. Checking too many at once may slow your browser.
