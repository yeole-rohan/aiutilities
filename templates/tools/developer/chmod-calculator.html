Frequently Asked Questions

Why does chmod use numbers? ▼
Each permission is a bit: r=4, w=2, x=1. You add them together — rwx = 4+2+1 = 7, rw- = 4+2 = 6, r-- = 4. Three digits cover owner, group, others (e.g., 755 = rwx|r-x|r-x).
What is the safest permission for web files? ▼
For web files: 644 (rw-r--r--) for static files, 755 (rwxr-xr-x) for directories and scripts. Never use 777 in production — it allows anyone to write to the file.
What does "execute" mean for directories? ▼
For directories, the execute bit means "can enter" (cd into) the directory. Without it, even if you have read permission, you cannot list or access files inside.
