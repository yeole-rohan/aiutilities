Frequently Asked Questions

What is Markdown? ▼
Markdown is a lightweight markup language — you write plain text with simple symbols (*, #, >, `) and it is rendered as formatted HTML. It is used on GitHub, Reddit, Discord, and many CMSes.
How do I make a heading? ▼
Start a line with # for H1, ## for H2, ### for H3. Example: ## My Section Title
How do I add a link? ▼
Use [link text](https://example.com) syntax. You can also use the Link toolbar button to wrap selected text automatically.
Does it support tables? ▼
Yes — use | to separate columns and --- for the header separator row. Example: | Col1 | Col2 |
