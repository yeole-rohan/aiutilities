Frequently Asked Questions

How much does CSS minification reduce file size? ▼
Typically 20–50% depending on how many comments and how much whitespace is in your source. Well-structured CSS with lots of comments compresses the most.
Does minification change the behaviour of the CSS? ▼
No — whitespace and comments have no effect on CSS rendering. The minified output is functionally identical to the original.
Should I use this in a production build pipeline? ▼
For serious projects, integrate PostCSS, cssnano, or a bundler like webpack or Vite for more advanced optimisations. This tool is ideal for quick one-off minification.
