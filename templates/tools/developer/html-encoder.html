Frequently Asked Questions

Why do I need to encode HTML? ▼
If you display user-supplied text in a web page without encoding, characters like < and > could be interpreted as HTML tags, causing layout breaks or XSS security vulnerabilities.
What are the most common HTML entities? ▼
< for <, > for >, & for &, " for double quotes, and   for a non-breaking space.
Does this prevent XSS attacks? ▼
HTML-encoding untrusted output is the primary defence against reflected XSS. Always encode user input before rendering it in HTML.
