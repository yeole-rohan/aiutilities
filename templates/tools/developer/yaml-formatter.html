Frequently Asked Questions

What YAML version is supported? ▼
This tool uses the js-yaml library, which supports YAML 1.2. All modern YAML used in Docker, Kubernetes, GitHub Actions, and similar tools is fully supported.
Can I convert JSON to YAML? ▼
Not in this tool — use the JSON Formatter tool instead, which focuses on JSON operations. This tool converts YAML → JSON. A JSON → YAML converter may be added separately.
Does it support multi-document YAML? ▼
Multi-document YAML (separated by ---) is partially supported for formatting. For JSON conversion, only the first document is converted. Future updates may add full multi-doc support.
