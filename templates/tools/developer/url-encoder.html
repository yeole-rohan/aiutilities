encodeURIComponent vs encodeURI

encodeURIComponent (Component mode)

Encodes everything except: A–Z a–z 0–9 - _ . ! ~ * ' ( )

Use for individual query parameter values where &, =, +, / must be escaped: hello world → hello%20world

encodeURI (Full URL mode)

Leaves URL structure intact: preserves :// / ? = & #

Use to encode a complete URL where you want to keep the structure but escape spaces and special chars.

Frequently Asked Questions

What is the difference between encodeURIComponent and encodeURI? ▼
encodeURIComponent encodes everything except letters, digits, and a few safe symbols. encodeURI preserves URI structure characters like /, ?, #, &, and = so the URL stays valid.
Why do spaces become %20 or +? ▼
In URL encoding, spaces are encoded as %20 (RFC 3986) or + (application/x-www-form-urlencoded). Both are valid; %20 is more universal.
When should I URL-encode data? ▼
Always encode query parameter values that may contain special characters like &, =, spaces, or non-ASCII characters before adding them to a URL.
