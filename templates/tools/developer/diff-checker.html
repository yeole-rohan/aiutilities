Frequently Asked Questions

How does the diff algorithm work? ▼
The tool uses the Longest Common Subsequence (LCS) algorithm — the same approach used by git diff — to find the smallest set of additions and deletions that transforms one text into the other.
Can I use it to compare code files? ▼
Yes — paste code from any language. The diff is purely text-based, so it works for any plain text including code, JSON, Markdown, or configuration files.
What do the colours mean? ▼
Red indicates a line that was removed from the original. Green indicates a line added in the new version. White lines are unchanged.
