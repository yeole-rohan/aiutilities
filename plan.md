# AIUtilities — Project Plan

A free online utility tools site targeting ~600–700 distinct tool URLs across 24 categories.
Source: Google Ads keyword research (Apr 2025 – Mar 2026, ~2,403 keywords, 319M monthly searches).

Build rule: **if it's a self-contained stateless utility tool → build it.**
Flag rule: if it requires persistent infrastructure, user data storage, or platform API auth → it's a product, not a tool (see §25).

We will be building 10 tools or pages/day to keep up with google crwaling budget.

## §25 — Out-of-Scope (Products, Not Tools)

These require persistent infrastructure, OAuth, or multi-session state — they are standalone SaaS products, not utility tools:

| Item | Reason |
|---|---|
| AI chatbot builder | Full NLP platform, training data, deployment infrastructure |
| AI agent builder | Orchestration engine, tool-chaining, API routing |
| Social media analytics tool | Needs live platform API auth + data storage |
| Full SEO audit platform (crawler) | Web crawler infrastructure |
| Job application tracker | Persistent multi-session user data |
| AI model training tool | GPU / ML infra |
| Resume builder (full SaaS) | Multi-template, ATS parsing pipeline, subscription gating |
| Email marketing generator | Campaign sequences, list management |
| Hashtag performance analyzer | Live platform API data |
| Social media post scheduler | OAuth + platform publishing APIs |

## §27 — URL Structure

```
/                          → Homepage (category grid + search)
/tools/                    → All tools index
/tools/<category>/         → Category page (e.g. /tools/calculators/)
/tools/<category>/<slug>/  → Individual tool (e.g. /tools/calculators/age-calculator/)
/ai/                       → AI tools index
/ai/<slug>/                → AI-powered tool
/sitemap.xml               → Auto-generated XML sitemap
/robots.txt                → Robots file
/privacy/                  → Privacy policy
/terms/                    → Terms of service
```

## §28 — Tech Stack

| Layer | Choice |
|---|---|
| Framework | Django 4.2 |

| AI | Anthropic Claude API (claude-sonnet-4-6) |
| Static files | Whitenoise |
| Deployment | Docker + Gunicorn + Nginx |
